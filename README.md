# F사 운영팀 첫 해 — In-Tray Exercise

신임 팀장이 1년 동안 받은편지함, 리더 회의, 면담, 평가를 처리하며 일을 맡기고, 평가하고, 자원을 나누고, 설명하는 방식을 돌아보는 웹 기반 In-Tray Exercise입니다.

- 브라우저에서 `index.html`을 열면 바로 실행됩니다. 빌드 단계는 없습니다.
- 진행 상황은 브라우저의 localStorage에 저장됩니다.
- 결산 화면에서 채점용 응답 묶음을 복사할 수 있습니다.
